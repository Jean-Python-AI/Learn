## Méthode de travail

Pour chaque sujet, relier :

1. l'intuition ;
2. la définition et les notations ;
3. un exemple calculé ;
4. une implémentation ou un exercice ;
5. les limites et les questions ouvertes.

Les notes de projet doivent pointer vers les concepts employés, et non les recopier intégralement.
