# CNN — Convolutional Neural Network

Un **CNN**, ou **réseau de neurones convolutif** ou a **Convolution Neural Network** en anglais, est une architecture adaptée aux données structurées spatialement, comme les images ou les grilles de jeu.


Un **CNN** utilise une série de convolutions pour néttoyer les images, retirer le bruit, faire resortir les éléments important ou les grand trait, ...
