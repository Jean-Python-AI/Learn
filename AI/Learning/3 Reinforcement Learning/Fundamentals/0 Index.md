# Fondamentaux du reinforcement learning

> Les cinq concepts ci-dessous décrivent la boucle minimale d'un problème de décision séquentielle.

$$
s_t \xrightarrow{\text{agent}} a_t
\xrightarrow{\text{environnement}} (r_{t+1}, s_{t+1}).
$$

- [[AI/Learning/3 Reinforcement Learning/Fundamentals/Agent|Agent]] — le système qui choisit les actions.
- [[AI/Learning/3 Reinforcement Learning/Fundamentals/Environement|Environnement]] — le monde avec lequel l'agent interagit.
- [[AI/Learning/3 Reinforcement Learning/Fundamentals/State|État]] — l'information utilisée pour décider.
- [[AI/Learning/3 Reinforcement Learning/Fundamentals/Action|Action]] — le choix appliqué à l'environnement.
- [[AI/Learning/3 Reinforcement Learning/Fundamentals/Reward|Récompense]] — le signal qui oriente l'apprentissage.

La règle de décision de l'agent est détaillée dans [[AI/Learning/3 Reinforcement Learning/Policy/0 Index|Policy]].
