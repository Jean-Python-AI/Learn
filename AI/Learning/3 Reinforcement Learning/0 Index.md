Le **R**einforcement **L**earning consiste à apprendre à un agent quelque chose pour le quelle ont a pas la réponsses, quelque chose pour le quelle ont sait juste dire ceci est bon ou mauvais.

Dans le RL, il y a
- un agent  : ce qui est directement contrôlable
- un environement : ce avec quoi l'agent intéragit
L'objectif est de donné des récompences ou "punissions" au modèle pour qu'il apprenne à maximiser ces points.

![[RL.svg|692]]
- $state$ : position, vélocity, pixel color, ...
- $action$ : motor speed, direction, ...
